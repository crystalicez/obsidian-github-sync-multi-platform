## Test-only fix

- `scripts/obsidian-live-ui-cleanup.mjs`: `cleanupGeneratedUiEvidence(runRoot, {repoRoot,...})` requires an exact 16-hex synthetic run ID directly under the repository's `.tmp/obsidian-live-github-e2e` parent, then removes only two exact screenshot filenames under the sibling test evidence directory. **No recursive deletion** of other runs, no arbitrary caller-provided file path. Idempotent; bounded retry for Windows sharing errors; fail-closed on invalid paths.
- `scripts/run-obsidian-live-github-ui.mjs`: invokes evidence cleanup in `finally` after terminating the owned instance and cleaning the synthetic vault. A failed evidence cleanup marks the test failed. Successful run reports `screenshotCaptured` while omitting dangling screenshot file paths once evidence has been disposed.
- `tests/v4/obsidian-live-ui-evidence-cleanup.test.ts`: **3/3 PASS** locally with real synthetic files: removes only own two screenshots and retains other run; rejects out-of-root/malformed names without any remove call; and retries an injected `EBUSY` without broadening deletion.
